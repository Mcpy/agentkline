# v0.5 P2 — 指标通道收敛

日期：2026-10-17（dsh）。前置：P0（Vela 0.8.4）+ P1（历史通道原生化，含修复轮 2）。

## 目标
成交量交 Vela 原生（store 驱动，错位类问题结构性消失）；legacy 指标通道收敛到官方 emit port 的最小形态；
删除 seriesMap 占位注册表与 LWC 残留；交互/布局语义不变（vela 原生适配原则）。

## 改动
- 成交量原生化：构造选项 `volume: true`（0.8.4 `maybeAutoAddVolume` 官方入口，独立 pane、store 驱动）；
  ready 后按 0.4 涨跌色配 `setInputs({upColor, downColor})`（原生输入项实测存在：upColor/downColor/heightPct）；
  pane 顶位语义沿用 `_nativePaneLayout` 的 move 逻辑（isVol 识别扩展 nativeType='volume'）。
  删除：ak-vol 组 emit 分支、`_ensureType('ak-vol')`、`addNativeIndicator('ak-vol')`。
- legacy 通道收敛（未映射脚本 kdj/tenp/自定义）：保留 registerNativeIndicator+ctx.emit
  （PoC P1 实证的官方 values 直喂通道，单 ctx 多 series 为官方语义非 workaround）；
  删除 `reEmitAll` 全扫 → `reEmitLegacyGroups`（ak-main + ak-sub::*）；
  `state.seriesMap` 占位注册表与 `_syncSeriesMap` 全删 → `_emitLines` emit 注册表
  （instId→已 emit 线数；结构变化判定与 ws.js hadSeries 门控改读它，导出 `legacySeriesCount`）。
- TAIL-align 定性更正：P1 不变量「镜像 ≡ 服务端 store」下 off=bars.len−values.len 为**精确索引对齐**
  （非启发式）；注释更名，保留瞬态乱序时 null 点降级。
- LWC 残留清扫：删 `frontend/src/lwc.js`；state.js 删 charts/series/seriesMap/subplotDivs/subplotSeries/
  _crosshairSyncing/_hoverChartKey；render.js 删 `_clearSubplotDom` 及调用。
- ws.js：hadSeries 门控改 `legacySeriesCount`。

## 验证（playwright-cdp + 服务端）
- `__akInputs()` = [{type:'volume', keys:[upColor,downColor,heightPct]}] → 原生 volume 在位且配色输入生效。
- REST 加 kdj（未映射）→ 200；`__akInputs()` 增 {type:'ak-sub::kdj'}；芯片条出「KDJ(9) [副图]」。
- legacy+native 共存左滑：200→401 ✓（历史通道不受指标组合影响）。
- test_e2e.py：129 passed, 0 failed。
