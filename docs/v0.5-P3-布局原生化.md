# v0.5 P3 — 布局原生化（单路径）

日期：2026-10-17（dsh）。前置：P0（0.8.4）+ P1（历史原生化）+ P2（指标通道收敛）。

## 目标
删除 OVERHEAD 像素校准常数与 legacy/原生双布局路径；volume pane 高度语义对齐 0.4（独立顶位）；
交互/滚动承诺不变（主图主导、容器总高=Σ目标、超出 wheel 翻）。

## 考古结论（0.8.4）
- 无像素级 pane API；官方旋钮 = `heightWeight`（默认 price=3、其余=1）。
- 原生 volume 注册为 `paneHint:'price', overlay:true`（默认叠在 price pane）；
  独立 pane 官方入口 = handle.`moveTo({newPane:true})`（resolveMoveTarget 考古确认 newPane 语义）；
  自动挂载时机可晚于 chart.ready → 移入布局路径补捉（每图一次 _volMoved 旗标）。
- paneManagement 能力门：renderer.capabilities.paneManagement + setIndicatorPane（本环境为 true）。

## 改动（vela_adapter.js 单文件）
- 删除：`OVERHEAD=33` 常数、`_paneTargets`、`_relayoutPanes`（含 legacy 分支与一处 `changed` 未定义
  的潜伏 ReferenceError——kdj 在板时该路径必抛）、`_nativePaneLayout/_nativePaneLayoutNow` 双路径。
- 新增单路径 `_layoutPanes/_layoutPanesNow`：
  ① volume 补捉 moveTo({newPane:true})；② vol pane move 至 index 1（0.4 顶位语义）；
  ③ 每 pane `heightWeight = _paneWeight(p)`（price=MAIN_H/vol=VOL_H/sub=sp.height||150，目标即权重，零校准）；
  ④ 容器高 = Σ 权重 px（仅变化时写 + resize，防 ResizeObserver 环）。
- ready 路径：volume 配色 setInputs(upColor/downColor)；`setTimeout(_layoutPanes,400)` 补捉晚挂载。

## 验证（playwright-cdp pane 级 dump + e2e）
- base：panes=[price, pane-native-1(Volume)]，容器 560px = 450+110 精确；
- +kdj(legacy emit)：710px；+rsi(原生副图)：860px；删 kdj：710px 且 pane 移除、rsi 保留；
- 带 volume+rsi 左滑：200→401 ✓；test_e2e.py 129/129 ✓。
- 语义注记：pane 实际像素 = 权重占 (容器−chrome) 的比例，主图≈450 减去 chrome 份额（比例制，非逐像素校准）；
  像素级观感留用户目验（诊断板 diag-lswipe，含 volume+rsi）。
