  - 镜像降格为缓存：`mergeIntoMirror` 仅同步写（去重/单调守卫保留），供 reportView/legacy emit 使用。
  - 删除：`_genesisHead`（模块级永不重置闩锁）、`_lastDepthAt` 3s 冷却、`_pointerDown/_depthRetries` 指针门、
    `backfillOnce`、applyDataUpdateCore 的 shift>0 跳板、addIndicatorNative 不可达死代码与 `_nativeInflight`。
  - 新增 `extendHistory()`：左划单入口 = `setMarket({同market, bars=镜像长度+200})` → Vela extendDepth →
    backfillHistory 循环。不变量：镜像 ⊇ Vela BarStore ⇒ target 恒 > rawBars ⇒ 必走 backfill 分支而非头部 slice。

## 修复轮 2（用户复验反馈：美股/A股左滑不加载、A股成交量错位）
根因链（实证）：
1. 头部 GET 原用日历窗 `to-(limit+2)*step`：交易日缺口源（A股/美股）欠覆盖 → 镜像头（WS prepend 全量）跑在 Vela 头前 → 左滑阈值（比镜像头）恒假 → 首次加载后停摆；binance 7×24 无缺口故幸存。
2. 反向漂移：脚本按日历 span 超取（prepended 215-224 > limit）而客户端窗只取 limit+2 → 镜像头又比 Vela 头更旧 → 同类停摆（binance 亦中招）。
3. 成交量错位：P1 首版 prepend 后不再 reEmit → ak-vol 组 emit 停留旧长度，与蜡烛脱节。
4. 拖拽期间二次 setMarket 与 in-flight 合并碰撞 → 渲染头卡死（视口 pan 不进新区 → hit 恒假；fetch 探针实证第二次左滑零请求）。
修复：
- 服务端 `/api/kline` 新增 `until/limit` 计数窗（timestamp<until 取尾 limit 根，日历无关）；空窗返回 200+空集（genesis 探测非错误）。
- `service.backfill` 严格按 limit 截断 older（prepended ≡ 客户端窗容量 ⇒ 镜像头 ≡ Vela 头不变量）。
- 前端头部取数改为"先 until 窗、窗空才 backfill、再窗"；healGap 仍走 start/end 时间窗。
- `extendHistoryCore` 加事件驱动 in-flight 门（history:progress/complete + 3s 兜底超时 + _headFlights）。
- prepend 路径恢复 `refreshEmittedGroups()`（vol/legacy 组 emit 与蜡烛对齐）。
- 新增 `window.__akDebug`（extend/vr/head/inflight）排障钩子。
