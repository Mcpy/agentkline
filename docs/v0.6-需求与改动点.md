## 0. 版本叙事与哲学

### 0.1 六版排布（一版一步可验证，事件压轴）

| 版本 | 名 | 内容 | 工程量 | 验收 |
|------|----|------|--------|------|
| **0.6.0** | 向量内核 | signal 契约落地+结果实例模型+run_backtest 接口面+builtin 向量引擎+双区面板最简+最简呈现两件 | 中大 | signal 策略跑通出结果 |
| **0.6.1** | 原版对齐 | engine-vibe 插件包（独立仓库）+golden test 体系 | 中 | **"结果和原版一样"**（builtin↔Vibe 逐数对齐） |
| **0.6.2** | 现场呈现 | 六件套补全+差异五刀+组件画廊+归因 skill | 中 | 对标共识不缺、差异可见 |
| **0.6.3** | 持久化 | JSON 名册+结果实例产物落盘+启动恢复 | 小 | 重启不丢 |
| **0.6.4** | 事件内核 | event 契约落地+builtin 事件驱动器+两式互验 | 中大 | event 跑通、两式对账 |
| **0.6.5** | 三引擎对齐 | engine-backtrader 插件包+golden test 扩展 | 中 | 三引擎结果一致 |

- 排布原则：每版闭环（跑了能看→结果可信→看得爽→关机不丢→事件收官）；**事件压轴**（event 需撮合核/契约/结果模型全稳，排最后等地基）；版本号=步骤非大小，全进 0.6 带向后兼容增量，攒批发版。
- 范例双仓独立发版解耦：Vibe 随 0.6.1、backtrader 随 0.6.5。

### 0.2 设计哲学

1. **引擎出秤，我们出铭牌、检定证、读数规范**：成交/账务/单位=引擎撮合私事（黑箱）；我们定 caps 能力声明、golden test 口径审计、结果 schema——适配层只翻译输入归一化输出，不碰秤砣。
2. **结果长在 K 线上，不长在报表里**：结果是"现场"上的图层（同轴联动/打点在 bar 上/统计卡浮角落）——AI 归因叙事的物质基础。
3. **画板=插件宿主**：数据（datasource）/策略（strategy）/引擎（backtest engine）三层插件化，呈现层是产品差异点；builtin/custom 双根同构（引擎也有 builtin）。
4. **扩展性靠契约演进规则，不靠继承树**：钩子只增不改｜ctx 面只增不删｜返回结构只增列不改列。
5. **诚实条款**：缺的机制偏保守+executionAssumptions 亮牌绝不装有；事件驱动=「高保真模拟」非「生产级回测」。

## 1. R1 引擎插件体系

### 1.1 架构（四层图景）

```
数据层（0.4 已有）  datasource 插件 → board ohlcv
策略层（0.4 占位）  kind=strategy   → 信号/意图（本单 §2）
引擎层（0.6 新增）  backtest engine → 规范化结果（本单 §1）
呈现层（0.6 主场）  结果实例        → 六件套+AI 归因（本单 §6/§7）
```

### 1.2 接口三契约

**① 结果契约（硬规范，范式无关）**：
```
{ equity[], trades[], stats{}, holdings?/orders?(过程数据), executionAssumptions(诚实声明) }
```
- 口径合规条款（golden test 验收，任何引擎插件必须过）：收益率=价格相对 P尾/P头-1 **禁止复利乘积**（#872）；年化因子按市场日历（股票 252/crypto 365/外汇 260+日内 bars_per_day 按源）；回撤 HWM 锚=initial_cash；pnl_pct 分母=entry_margin；费用双轨（fill.fee 逐笔 vs 回合 commission=进出合计）；加减仓 compressed-position 记账；`end_of_backtest` 强平语义；warmup/evaluation_start 预热段排除绩效；小样本守卫（单 bar std/溢出）；sign-safe returns。
**② 调用范式**：`run_backtest(engine, board_ohlcv, strategy, params) → result_id`——引擎黑箱，画板喂数据、收结果、上图。
**③ 策略契约**：见 §2（signal/event 两式）。

### 1.3 插件工程形态（许可隔离=用户裁定）

- 主包（Apache-2.0）**零引擎依赖**：只放接口 ABC+entry_points 发现+CONFIG_SCHEMA 渲染数据结构；
- 引擎插件=独立 git 仓库独立 pip 包（一插件一包各包各许可）：`agentkline-engine-vibe`（MIT）、`agentkline-engine-backtrader`（GPL-3.0）；
- 引擎插件声明：`CONFIG_SCHEMA`（扩展区动态表单）+ caps `{"signal": bool, "event": bool, "leverage": bool}`（能力铭牌，匹配校验 CAPS_MISMATCH 同族）+ 许可声明（加载处提示"此引擎由第三方包提供，许可 X"——发现≠分发）；
- 保险带：永不组合分发（不打全家桶）；接口留进程隔离选项（默认同进程）；文档明示各插件许可。

### 1.4 范例插件（双向翻译演习=接口试金石）

- `engine-vibe`：signal 式原生（generate(data_map)→signals 直通）；shim+输出归一化；
- `engine-backtrader`：event 式 shim（策略翻译/订单映射 order_target_percent）；**限价/止损单能力=逃生舱面**（引擎原生格式策略可用）非标准面。

## 2. R2 strategy 脚本契约（kind=strategy，两式）

### 2.1 形态定案

**函数式 + 可选钩子函数族 + ctx.state**（否决类继承——真类继承仅两家框架文化产物，QD 以模块函数+g 验证函数式路线；对 AI 生成/ast 校验/安全沙箱友好）。演进三承诺入契约文本（见 0.2-4）。

### 2.2 signal 式（向量化/粗筛）

```python
STRATEGY_MODE = "signal"; NAME = "双均线快筛"; WARMUP = 50
PROTECTION = {"stop_loss_pct": 0.05, "take_profit_pct": 0.1}   # 契约级保护，引擎消费
PARAMS = {"fast": 10, "slow": 50}                              # 策略私有，脚本消费

def main(params, ohlcv):
    ...
    return {"target": [...], "reason": [...]}   # target=目标仓位权重表(-1~1)；reason=归因原材料
```

### 2.3 event 式（事件驱动/精算）

```python
STRATEGY_MODE = "event"
def initialize(ctx):
    ctx.state["x"] = 0        # 跨bar记忆的家（run 隔离），模块级可变变量禁用
def on_bar(ctx, bar):
    ctx.target(1.0, reason="ma_cross_up")   # 唯一写出口（目标仓位语义）
    # ctx.close(reason=...)
```
- ctx 最小面：只读 `data`（渐进 ohlcv 防未来函数）/`position(size,avg_cost,pl)`/`cash`/`equity`/`params`/`now`；写出 `target(weight, reason=, sl_pct=, tp_pct=)`/`close(reason=)`；
- 一期**无 buy/sell 订单 API**（订单生命周期随"订单事件扩展"开闸，届时新钩子 `on_order_filled` 可选新增，老策略无感）；ctx 给类型定义（Protocol）供 IDE。

### 2.4 声明六件套（ast 静态抽取家族，save_script 保存即验）

`STRATEGY_MODE`（signal|event）｜`NAME`/`DESC`｜`WARMUP`（预热排除绩效）｜`PROTECTION`（键名**白名单**：一期 stop_loss_pct/take_profit_pct，自造键报错）｜`PARAMS`（策略私有）。
覆盖语义=声明默认+run 时覆盖。校验：MODE_MISMATCH（signal 必有 main/event 必有 on_bar）+PROTECTION 白名单+声明族字面合法性。

## 3. R3 builtin 引擎（主包内置，开箱即用）

- **一个撮合核+两个驱动器**：signal 驱动（读目标仓位表）/事件驱动（逐 bar 喂 ctx）共用同一账务——两式对账的前提；
- 撮合核范围（=§4 清单 A）：市价、**收盘确认、次开盘成交**（无未来函数时序）、费用（比例佣金）/滑点（比例）、entry 级保护（bar 内触价按触发价、保守优先止损>止盈）、1x 现金账、连续数量；
- 统计输出=口径合规全家桶（§1.2 条款）+基准对照（买入持有+excess）；
- builtin **走插件接口实现**（参考实现自证接口+golden test 内部基准；eventlite 搁置件转正）；
- 安全：沿 0.4 现状（save_script 静态校验+exec）；L2 沙箱留池。

## 4. R4 引擎边界（三清单）

- **清单 A（产品与契约边界）**：单标的（board 现场 ohlcv 一次 run）单周期；杠杆**跟随引擎能力**（caps 声明，支持即开放，唯亮牌义务）；只回测不碰纸面/实盘（铁律）；max_bars=50000 继承；同步运行+超时上限+串行锁；
- **清单 B（引擎原样声明）**：各插件撮合能力照原样（backtrader 高级单=逃生舱面）；entry 保护由插件映射自家机制；lot 取整=引擎私事 executionAssumptions 转述；
- **清单 C（规划池）**：见 §13。

## 5. R5 结果实例模型

- **冻结实验记录语义**：跑完即冻结，**重跑=新建实例不覆盖**（实验日志不可改写——归因对照的基础）；血统=blob 族跟现场共存亡不归档；
- 字段：`result_id`（自动 macd_2 式）+`display_name`（可改）+引擎指纹（插件 id/版本/扩展参数）+策略指纹（脚本 id/STRATEGY_MODE/params）+运行快照（标准区参数+executionAssumptions）+**数据指纹**（board/tf/数据窗口 bar 数首尾时间，数据变更后旧结果标注"基于旧快照"不自动失效）+产物（equity[]/trades[]/stats{}/过程）；
- **可手动删除**（UI 删除入口+二次确认+MCP delete_result）——撕页可、涂改不可；
- 性能：get_result **摘要先行**（stats+元信息），equity/trades 窗口分页（v0.4 §10 教训）；
- 归因派生：trades→markers 是派生物（归因 skill 调 set_markers），不入结果存储。

## 6. R6 可视化呈现（六件套+差异五刀）

**总原则：结果图层叠加现场**（非独立报表页）。
1. equity 副图（0.4 subplot 体系；单结果绝对值/多结果归一 100 叠加+基准虚线+同轴联动）；
2. 交易 marker（set_markers 复用；选中结果打点图层心智/reason 文本/亏损单红显）；
3. 统计卡（右上浮层；核心指标+executionAssumptions 亮牌入口+含杠杆警示；多结果对比表差异高亮）；
4. 对照视图（结果切换器挂身份证卡；trades 级差异后置）；
5. 持仓区间带（tractor beams 式：持仓段半透明背景）；
6. 交易明细面板（trades 表格，点击行跳图上 marker 表图联动）。

**差异五刀（产品差异点）**：AI 运镜叙事｜reason 语义通道｜多结果同场对照｜三族资产同场（结果 marker+划线+标记）｜executionAssumptions 亮牌。
**回撤呈现**=equity 子图 underwater 内置渲染（净值与高水位间填充），**不动画线系统**。
**region 矩形型**（AI 叙事区间标注笔，画线第四种笔"面"，API 笔先例）：0.6.x 实现，扩展留口。

**前端开发实践（工程义务）**：六件套独立组件模块（props 进数据出零全局依赖）+`dev_gallery.html` 常驻画廊（mock 数据渲染，AI 可浏览器 skill 自我验证）+主页面 import 同组件+feature flag（?beta/设置开关）控制暴露——零搬家零污染，画廊与主页面双处验证。

## 12. 否决设计清单（勿复活）

| 曾出现的主张 | 否决理由 |
|--------------|---------|
| `main→{trades,equity}` 脚本全算契约 | 策略产信号/意图+引擎算账（业界共识，AI 生成更稳口径统一） |
| 类继承策略契约 | 函数式+钩子族+ctx.state（QD 验证）；逃生舱=引擎原生格式除外 |
| 钦定纯信号+逃生舱统一 | 被 2.8 策略二式替代（范式二分诚实优于统一） |
| 回撤高亮进画线系统（⑤原案） | underwater 子图内置渲染替代；region 以"叙事标注笔"另立项 |
| 每引擎定制 UI / 纯通用面板 / 临时子页面调好并入 / 纯主页面直改 | 双区制 / 组件画廊+flag（搬家走样/半成品污染两病同除） |
| 事件引擎进 0.6.0 前段 | 事件压轴（需全局理解，等地基） |
| 引擎整包移植（backtrader 2500 行全搬） | 90% 用不上；插件化后移植降为插件实现细节 |
| backtrader/AGPL 代码进主包 | 许可隔离：主包零引擎代码 |
| 事件驱动="生产级回测"措辞 | =「高保真模拟」，executionAssumptions 不可省 |
| 引擎内核自建杠杆/资金费建模（一期） | 杠杆跟随引擎能力亮牌；自建入池 |
