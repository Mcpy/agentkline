# AgentKline 脚本编写指南

> 版本：v0.3.2 ｜ 面向：需要自定义指标 / 数据源脚本的开发者与 agent
> agent 侧权威版本见 `skills/script-authoring.md`（经 MCP `load_skill` 加载），本文与其保持一致。

AgentKline 的指标与数据源都是 **Python 脚本**，由 `script_engine` 在隔离命名空间
`exec` 执行，靠约定函数 `main` 交互。示例见 `scripts/`（`sma.py` 指标、
`mock_btc_data.py` / `ccxt_binance_btc.py` 数据源）。

## 指标脚本
- 定义 `main(params, ohlcv)`（兼容 `main(params)`）；全局注入 `params`、`ohlcv`
  （`[{timestamp(毫秒), open, high, low, close, volume}, ...]`）。
- 返回 `list`→单线 values；或 `dict{values, lines, markers}`；values 与 K 线**等长对齐**。
- 预热期用 `None` 占位，**不要返回 NaN**（v0.3.1 起服务端会清洗为 None，但应主动规避）。
- 可选元数据：`NAME`（根名）、`PARAMS`（默认参数）、`label(params)`（显示名）。
- 注册：`add_indicator(..., script="xxx.py", params={...})`（推荐）。

```python
PARAMS = {"period": 20}
def main(params, ohlcv):
    p = params.get("period", 20)
    closes = [b["close"] for b in ohlcv]
    out = [None] * len(closes)
    for i in range(p - 1, len(closes)):
        out[i] = round(sum(closes[i-p+1:i+1]) / p, 2)
    return out
```

## 数据源脚本
- 定义 `main(params)`，返回升序 K 线 `list`（或 `{"data": [...]}`），字段同上。
- 支持 `params["until"]`（毫秒）才能被 `load_history` 向左回溯
  （`ccxt_binance_btc` 支持、`mock` 不支持）。
- 注册：`set_datasource(..., path="xxx.py", poll_interval=0)`；`poll_interval>0` 轮询实时。

## 沙箱边界
当前 L1 = 直接 `exec`，**不限制 import**（内部调试）；L2 subprocess 隔离在路线图。
脚本需自律：无死循环、无恶意 IO、控制时长。

## 自检
main 签名正确；values 等长、warmup 用 None、无 NaN；数据源全字段/毫秒/升序；
需回溯实现 until；无死循环。
