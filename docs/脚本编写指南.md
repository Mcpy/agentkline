# AgentKline 脚本编写指南（v0.4）

> 版本：v0.4.0 ｜ 面向：需要自定义指标 / 数据源脚本的开发者与 agent
> agent 侧权威版本见 `skills/script-authoring.md`（MCP `load_skill` 可取）；本文与其同步维护。

## 0. 两类脚本与存放（双根三层）

| kind | 契约 | 目录 |
|------|------|------|
| `datasource` | `main(params[, until]) → bars[]` | `<root>/datasource/` |
| `indicator` | `main(params, ohlcv) → values \| {values,lines,markers}` | `<root>/indicator/` |
| `strategy` | 占位（本版不执行） | `<root>/strategy/` |

- **双根**：builtin = 包内 `agentkline/resources/scripts/`（随包发布、只读）；custom = `<scripts_dir>/`（默认项目 `scripts/`，可写）。
- **id = `kind/文件名stem`**（如 `indicator/macd`）是一切引用的唯一格式；裸文件名硬切报错 `SCRIPT_BAD_ID`。stem 限 `[a-z0-9_]+`。
- 同名 shadow：custom 优先；`list_scripts` 返回 `source` 字段标明实际加载根。
- 契约由**所在目录**推断，文件内不声明 KIND。
- AI/用户写脚本只落 custom：MCP `save_script(id, code)` 或 `POST /api/scripts`（保存即校验）。

## 1. 模块顶层字面常量族（ast 静态抽取，列目录零 exec）

```python
NAME = "MACD"            # 显示名（字符串字面）
DESC = "DIF/DEA+红绿柱"   # 描述（AI 选脚本依据；docstring 兜底）
PARAMS = {"fast": 12}    # 默认参数（字面 dict）
CAPS = {"backfill": True, "symbols": False, "ticker": False}  # 能力徽章（字面 dict）
IDENTITY = ["symbol"]    # 板锁身份键（字面 list）
```

- 常量必须**字面可解析**（ast.literal_eval）；写表达式等于未声明。
- **CAPS 声明⇒必须实现**，否则加载/保存报 `CAPS_MISMATCH`：
  `backfill:True` ⇒ `main` 签名显式含 `until`；`symbols:True` ⇒ 定义 `list_symbols(query)`；`ticker:True` ⇒ 定义 `ticker(params)`。
  不声明 = 无能力（fail-closed）。custom 旧脚本缺 CAPS 仅 warning。
- **IDENTITY** = 哪些 params 键构成"数据身份"（板锁快照它们）：在线源典型 `["symbol"]`；CSV 等"路径可换"源用 `[]`（path 归操作参数）；固定数据源 `[]`。
- CAPS 门控的产品功能：`backfill`=左滚自动补历史；`symbols`=标的搜索索引入场券；`ticker`=自选表报价（v0.4.1）。

## 2. 指标脚本

```python
def main(params, ohlcv):
    close = [b["close"] for b in ohlcv]
    out = [None] * len(close)          # warmup 用 None，禁 NaN/Inf
    ...
    return out                          # 或 {"values":..., "lines":[...], "markers":[...]}
```

- 与 K 线等长；warmup 段填 `None`；**禁 NaN/Inf**（服务端 choke point 会清洗为 null，但脚本应自洁）。
- `lines` 每项 `{name,type:line|histogram,values,style?}`；histogram 无 style 时前端自动红绿。
- 可选 `label(params) -> str` 自定义显示名（优先于 NAME+参数拼接）。
- 重算尾窗：服务端只喂**最近 max_window=5000 根**（config `limits.max_window`）——长记忆参数勿超窗。
- 落盘方式：`add_indicator(script="indicator/xxx", params=...)` 建 **recipe 实例**（随 K 线自动重算）；
  直接给 values/lines = **冻结 blob**（钉死单周期，不重算）。实例把手 inst_id（撞名 INST_EXISTS / 自动 macd_2 式）。

## 3. 数据源脚本

```python
def main(params, until=None):          # until=毫秒时间戳（回溯调用时由系统注入签名参）
    ...
    return [{"timestamp": ms, "open":..., "high":..., "low":..., "close":..., "volume":...}, ...]
```

- `timestamp` 一律**毫秒**。
- 运行模式 poll/once 是**槽位配置**（`poll_s`），不是脚本属性；poll 时系统周期调用 `main(params)` 合并尾部。
- `until` 回溯：返回 **早于 until** 的 bars；历史有界就在边界返回空（前端左滚自然停）。
  回溯必须**可重放且跨窗连续**（同 (身份,日期) 永远同值；参考内置 mock 的"创世点+逐日种子"范式）。
- `list_symbols(query)`：返回 `[{"symbol":..., "display":...}]`；**首用全量建索引后本地过滤**（TTL 日级），
  实现时不要假设被高频调用；搜索永不穿透交易所。
- `ticker(params)`：返回 `{"last":..., "change":..., "change_pct":...}`（v0.4.1 自选表用）。
- 上限护栏：单槽 > `max_bars_per_slot`（默认 50000）截最旧 + `dropped` 回报——**别内嵌巨量数据**，
  优先脚本自拉（新鲜+可重放）；save_script >100KB 告警。

## 4. 数据家族范式（离线多面板正解）

多数据集/多周期 = **一个脚本**内多份数据，用**非身份** params 键分片（如 `dataset`/`interval`），槽位名自由。
**禁止为多面板拆多脚本**——板锁全等校验会拒（同板所有槽必须同 script+同 identity）。

## 5. 板锁语义（写脚本时要懂的上下文）

- 画板 = 某标的的分析**现场**：`source_lock = {script, identity快照}`，建板即锁/空板首配即锁。
- 换标的/换源 = 新建画板（撞锁 `SOURCE_LOCKED` + suggestion 一键改道）；IDENTITY 之外的 params 自由改（改即重拉）。
- 在线板加周期：系统自动注入 `{identity + interval}` 配置新槽——脚本应读 `params["interval"]` 支持多周期。

## 6. 沙箱边界

L1 = 直接 `exec` 隔离命名空间，**不限制 import**（内部调试用）；L2 subprocess 在规划池。
脚本需自律：无死循环、无恶意 IO、无网络滥打（list_symbols 尤其）。别指望沙箱兜底。

## 7. 自检清单

- [ ] id 格式 kind/name？stem 合法？
- [ ] NAME/DESC/PARAMS/CAPS/IDENTITY 全字面？
- [ ] CAPS 与实实现一致（backfill⇒until 参 / symbols⇒list_symbols / ticker⇒ticker）？
- [ ] 指标：等长、warmup=None、无 NaN？
- [ ] 数据源：timestamp 毫秒？until 返回早于 until？跨窗连续可重放？
- [ ] 没内嵌超量数据？多面板走数据家族单脚本？

## 8. 周期语义（v0.4 优化点 2）

- 数据源可声明字面常量 `INTERVALS = ["1m", "15m", "1h", "4h", "1d", "1w", ...]`（ast 抽取族成员）：
  **声明 = 实时源**，享受周期面板全套能力；不声明 = 离线源（csv/固定数据），周期槽保持自由命名面板语义。
- 系统行为：
  - 建板即锁（用户搜索流）默认周期 = `["15m","1h","4h","1d","1w"] ∩ INTERVALS`（初始当前=1d 在列则用）；
    **所有初始槽自动注入配置**，不留空槽；空板首配锁（AI 路径）尊重 AI 自建槽不扩。
  - 每个槽配置恒被注入 `interval=槽名`（§2.2 系统注入）：脚本读 `params["interval"]` 出对应粒度，
    不要自行假设周期；IDENTITY 不含 interval（同标的跨周期=同一现场的多面板）。
  - 前端锁定板周期行显示"+"按钮，下拉= `INTERVALS − 已有`；加入后服务端按短→长排序（15m<30m<1h<4h<1d<1w<1M）。
  - 加不支持的周期 → `INTERVAL_UNSUPPORTED`（400，报错文案带支持表）。
  - 切到"存在但未配置"的槽（存量板/漏配路径）→ 懒配置自动注入出图。
- 脚本作者义务：INTERVALS 里列的每档都要真能出对应粒度数据（别列假档）；单粒度源就老实声明单档。
