## 0. 版本叙事与哲学

**版本图**：v0.4（✅ 已完成：交互画板）→ **v0.5（本单：Vela 换底）** → v0.6（回测引擎插件化六版 0.6.0–0.6.5，六件套长在 Vela 底上）。
**硬理由**：旧底铺新功能=最贵返工（六件套会在 LWC 做一遍换 Vela 又做一遍）；先换底一次半完成。

**哲学四条**：
1. **锁契约不锁版本号**——兼容基线=0.8.1 验过的 API 面（PoC 映射表=契约），版本跟着回归走；
2. **依赖引用非 fork**——Vela 代码不进仓库，只调公开 API（fork=上游停更时的应急预案，非日常）；
3. **Vela 只管画，算全是咱们的**——数据/指标/策略三类后端脚本一个不废；
4. **归因义务照履**——NOTICE=Apache §4(d) 许可组成部分，不可裸关。

## 2. R2 适配层 `frontend/src/vela_adapter.js`

- **形态**：单文件原生 JS 模块 + script 标签引 `vela.global.min.js`（零构建链，PoC P5 已验）；
- **对上**：暴露 render.js 同名语义函数，**render.js 退化为薄壳**→UI 层零改；
- **纪律**：应用层不直接摸 Vela API，全经本文件——API 演进的唯一适配点；
- **映射表（=兼容基线契约，PoC 报告 §3）**：

| 咱们语义 | Vela 0.8.1 API | 备注 |
|---|---|---|
| 指标 values 主图叠加/副图 | `registerNativeIndicator({paneHint:'price'/'new'})`+`ctx.emit({series,fills})` | 每 board×indicator 一个 native type；更新=重 emit（patch 语义） |
| WS 历史/实时/切板 | `deps.dataFeed`：`load`/`subscribe(onBar)`/`setMarket` | feed 内桥接后端 WS |
| add_drawing/delete_drawing | `chart.drawings.add(type,{anchors:[{time,price}]})`/`.remove(id)` | type 白名单起步=hline/trendline/ray/box（+text 视觉限见 §10） |
| 画线持久化 | `drawings.toJSON()`/`fromJSON(doc)` | doc={version:1,drawings[]}——**深拷贝后存档**（活引用坑见 §10-⑤） |
| set_markers（交易点+reason） | `chart.marks.add({time,glyph,content:{panel}})`+`defineGroup({id:'trades'})` | 聚簇自动；reason=panel field |
| AI 划线族标记（箭头） | 同 marks（glyph letter/shape） | MarkerSeries 不绘（§10-②），marks lane 承担 |
| set_view_range | `chart.setVisibleRange({from,to})`/`setVisibleRangePreset` | epoch **ms**（注意换算） |
| equity 子图/持仓带/underwater（0.6） | native indicator `paneHint:'new'`+`fills[]`（eq↔peak）+backgrounds（持仓带候选） | fills 已验；backgrounds 同族字段低风险 |
| 指标设置面板（0.6） | native descriptor `inputsSchema/defaultInputs/setInputs` | |
| 事件桥 | `chart.on('drawing:created'/'mark:click'/'viewport:changed'/'market:changed'/...)` | drawing:updated/selected 未 fired（§10-①） |

## 3. R3 数据流（dataFeed 桥接）

- `deps.dataFeed` 注入自定义 MarketDataFeed，**零 provider 注册**；`load`（历史分页）+`subscribe(cfg,onBar)`（=WS 连接点）+切板走 `setMarket`；
- 事件时序对接：`load:start→history:progress→load:end→bar`（WS 推送→onBar）；
- **注意**：dataFeed 与 providers **同图互斥**（给了 dataFeed 则 provider API warn+no-op）——未来若要前端直连（快捷看盘板），按 **board 粒度**分模式，不混一张图。

## 4. R4 画线/标记迁移

- 画线 type **白名单**起步：`hline/trendline/ray/box`（74 种 DrawingTypeKey 可用，白名单=我们 add_drawing 的语义面控制）；anchor 契约 `{time,price}`（epoch ms）；
- **持久化格式定案**：存 **Vela 原生 DrawingsDocument**（{version:1,drawings[]}）——理由：往返无损已验+versioned 格式稳于自拟；存储层存 JSON 文档结构不变；**深拷贝存档**；
- marks：`group='trades'`（defineGroup）+content panel=reason 字段+同 bar 聚簇+`setGroupVisible/isGroupVisible` 做开关（§10-④）；
- AI 画线/标记 MCP 面不变（add_drawing/delete_drawing/set_markers 的参数与语义照 0.4 施工单）。
