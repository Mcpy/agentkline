## 0. 版本叙事与纪律

### 0.1 发布切分

| 版本 | 内容 |
|------|------|
| **v0.4.0** | 全模型重构（§1–§6）+ 性能三件套（§7）+ **P1 用户自助**（搜索建板/铭牌/身份证卡/SOURCE_LOCKED 一键改道）+ save_script 脚本生命周期闭环 + 内置脚本改造 + 文档/e2e 连锁 |
| **v0.4.1** | **P2 完整雷达**：watchlist CRUD + 面板 + quotes 轮询引擎 + `quotes_update`/`watchlist_changed` + 点行三态分发。⚠️ watchlist 存储结构自第一天即 `groups[] → rows[]`（默认组"观察"），为 0.4.2 免迁移 |
| **v0.4.2** | **分组**：组 CRUD、移组、组折叠（折叠组暂停报价轮询） |
| **v0.4.3** | 补丁预留位（修复攒批随版带出） |
| **规划池（0.5+，未定版号）** | 持久化、登录体系、L2 沙箱、画图交互扩展、回测（strategy 转正）。0.4.x 交付后另开规划轮 |

- 工具数分带：**v0.4.0 = 35 个 MCP 工具**（33 + save_script + search_symbols）；**v0.4.1 起 = 37**（+ get_watchlist/set_watchlist）。
- P1 留在 0.4.0 的理由：重构必须配可见新价值；开发内部排链=脚本体系→锁与 kline_source→搜索建板→性能，发版整块收口。
- 版本号纪律：大版本=破坏性契约变化；0.4.x=向后兼容增量（协议/存储/签名不动，"和平时期"）；补丁不单独发、攒批。
- 排产原则：**方案成熟度决定版本资格**，构想不进版本号。

### 0.2 设计哲学（一页纸）

1. **AI-first 不变**：把"操作图表"交给 AI，把"看懂并决策"留给人。用户自助只决定**看什么**；AI 仍垄断**怎么分析**。
2. **K 线真相层严格，指标结论层自由**（一切皆脚本）：每根 bar 必须可溯源到脚本配方可重放；指标允许冻结快照。
3. **一标的一板**：board = 某标的的分析**现场**（身份锁死），自选栏 = **雷达**；雷达发现目标 → 进入现场。换标的场景被模型层禁掉 → 归档机制不存在。
4. **锚定决定命运**：锚定计算的（recipe 指标）跟 K 线自动重算；锚定时空坐标的（markers/划线/blob）与现场共存亡——不归档、不迁移、不克隆。
5. **术语分层**：kind 层=`datasource/indicator/strategy`（脚本分类学）；接口层=`kline_source`（人与 AI 思维模型）；数据层=`ohlcv`（bar 字段与契约参数）。

## 1. R1 脚本体系

### 1.1 分类（kind）——目录即 kind，契约硬决定

| kind | 契约 | 说明 |
|------|------|------|
| `datasource` | `main(params) → bars[]`（list 或 `{data}`，每条 `{timestamp(ms),o,h,l,c,v}`） | 可选方法：`list_symbols(query)`、`ticker(params)`；`main` 声明 `until` 参数=可回溯 |
| `indicator` | `main(params, ohlcv) → values \| {values,lines,markers}` | 纯函数；warmup 用 None 禁 NaN（原有约定不变） |
| `strategy` | `main(params, ohlcv) → trades/equity/markers` | **本版仅占位**：目录建、枚举立名分，不实现执行路径 |

运行模式（poll/once）是**槽位配置属性**，不是脚本类别。

### 1.2 存储（双根三层）

```
agentkline/resources/scripts/{datasource,indicator,strategy}/   ← builtin：随 pip 包，运行时对人/AI 只读
<scripts_dir>/{datasource,indicator,strategy}/                  ← custom：可写；AI 落盘只进这里（默认项目 scripts/）
```

- 契约由所在目录推断 + 加载校验（文件内不声明 KIND）。
- 同名 shadow：查找顺序 custom→builtin；`list_scripts` 返回 `source` 字段；执行日志回报实际加载路径。
- path 全格式 `kind/name`（如 `indicator/macd`）：裸文件名旧引用一律 400 硬切，不迁就旧配置。
- 预留演化（不做）：name 即子目录的"脚本包"形态。

### 1.3 身份与元数据

- **id = `kind/文件名stem`**，唯一技术标识：API/状态/WS/板锁/日志只认 id。stem 校验 `[a-z0-9_]+`。脚本内部**不设可引用的 name**。
- 模块顶层**字面常量族**（ast.parse 静态抽取 + mtime 缓存，列目录永不 exec）：

| 常量 | 含义 | 约束 |
|------|------|------|
| `NAME` | 显示名（原"根名"语义废除） | 字符串 |
| `DESC` | 描述（docstring 兜底） | 字符串，AI 选脚本依据 |
| `PARAMS` | 默认参数 | **字面 dict** |
| `CAPS` | 能力徽章 | 字面 dict：`{"backfill": bool, "symbols": bool, "ticker": bool}`；不写=无能力（硬切，内置补行，用户旧脚本 warning） |
| `IDENTITY` | 板锁身份键 | 字面 list：`["symbol"]`/`[]`/`["symbol","start","end"]` 等，声明哪些 params 键构成数据身份 |

- 一致性校验：`backfill:True`⇒main 签名显式含 `until`；`symbols:True`⇒`def list_symbols`；`ticker:True`⇒`def ticker`；不符报 `CAPS_MISMATCH`。
- **CAPS 门控的产品功能**：`backfill`=图表左滚自动补历史；`symbols`=标的搜索索引入场券（不实现=搜不到，仍可裸输入 `@源名 裸符号` 直配）；`ticker`=自选表实时报价（无则回退末根 close）。

### 1.4 脚本工具接口

- **新增 `save_script(id, code)`**（MCP+agent REST）：只写 custom；**保存即校验**（CAPS/IDENTITY/PARAMS 字面合法性、目录 kind 一致性、主函数存在），错误当场返回。内置离线数据脚本标准模板写入 docstring。
- `list_scripts` 返回：`[{id, kind, source, display, desc, params, caps, identity}]`。
- `run_script` **窄身**：签名→`{script, params}`，执行并返回结果，**图上不留痕**；`save_as/indicator_name/scope` 删除。指标落盘=`save_script + add_indicator(script=...)`。

## 2. R2 数据源与板锁

### 2.1 一切皆脚本

- `push_ohlcv`（POST /api/ohlcv）与 `load_csv`（POST /api/load-csv）**永久出局**（不进 MCP 不进未来规划）。
- CSV = 内置 `datasource/csv` 脚本：`params={path, ...列映射}`；**IDENTITY=[]或["symbol"]，path 归操作参数**（防板锁吞 path）。
- AI 原始数据上图 = 写"固定数据脚本"（once 模式，数据内嵌）或**脚本自拉数据（优先推荐：新鲜+可重放）**。
- **数据家族脚本范式**（离线多面板的正解）：多数据集/多周期=**一个脚本**内多份数据，用非身份 params 键（如 `dataset`/`interval`）分片，槽位名自由。**禁止为多面板拆多脚本**（板锁全等校验会拒）。指南/skill 成文。

### 2.2 槽位配置（概念词 binding，接口词 kline_source）

```json
{ "script": "datasource/ccxt_binance", "params": {...}, "mode": "poll|once", "poll_s": 5 }
```

- 每槽唯一活动配置，新声明=替换（poll 切换即退订）。
- **配置与状态分家铁律**：`last_error/last_fetch/bars/next_due` 挂槽位 status，不进配置；配置永远 JSON 可序列化。
- `script/params`（身份部分见 2.3）变→自动重拉一次；仅 `poll_s` 变→不碰数据。
- **在线板加周期自动化**：新 tf 槽由系统注入 `{script, identity + interval}` 自动配置——用户点"+"手工加周期，无需 AI。
- **指标槽配置不对称**：无 poll（派生计算，K 线更新自动重算）；两态=script recipe / 冻结 blob（见 R3）。

### 2.3 板锁（v2 定案，v3 已否决勿复活）

- `board.source_lock = { script_id, identity: {IDENTITY 键→值快照} }`。
- **双路锁定**：`create_board(symbol, source_id?, params?)` 建板即锁；或空板（AI 专属）首配 `set_kline_source` 时锁定。
- **全槽全等校验**：任何槽配置必须 script_id 与 identity 均等于板锁，否则 `SOURCE_LOCKED`（once/poll 一视同仁；操作参数不受限）。
- 锁死内容=标的+源；换标的/换源必须新建板。`backfill` 的 `until` 是调用参数**不受锁**（现场自然生长）。
- `delete_kline_source` **退役**：换源被禁 ⇒ 断来源=伪需求；停轮询=poll_s 操作参数；配错源=删板重建。**不做克隆板**。
- **board 无 symbol 特殊字段**：标的存储唯一形态=source_lock.identity 快照；`identity.symbol ?? NAME ?? id` 仅为显示链。
- 错误文案即教育：`SOURCE_LOCKED` 附结构化 `suggestion: {action:"create_board", symbol, script, params}`——UI 一键改道（被拒配置自带新现场全部要素）；AI 见 suggestion 即从。
- 混合板否决：实时+回测同板=伪需求，开两个现场，walkthrough 切换。

### 2.4 backfill（原 load_history）

- 改名 `backfill`（与 `CAPS.backfill` 同词）。实现=读槽配置重放配方 + `until=<当前最早>`；源无 backfill 徽章→返回 0 并注明原因。
- 左滚触发条件不变（用户手动滚、程序化视口不触发）。

## 3. R3 指标实例模型

### 3.1 统一实体（三本户口合并）

现状债：`tf.indicators`/`tf.dynamic_indicators`/`board.board_indicators` 三处存储 → 收敛为两层：

- **实例登记处（board 级）**：`IndicatorInstance = { inst_id, kind: recipe|blob, script/params(recipe), tf_scope(recipe: board|timeframe), target(主图|副图名), display_name(默认 label(params) 可覆盖), style/lines_style 等渲染配置 }`
- **物化缓存（per tf）**：`{inst_id → values/lines}`（blob 的 values 即物化本体）。

### 3.2 规则

- `inst_id` 唯一把手（引用不再用脚本名）：**AI 传名撞名报错**（`INST_EXISTS`）；不传自动生成 `macd_2` 式。
- `add_indicator`：`script=`（id 格式）建 recipe 实例（随 K 线自动重算）；`values/lines` 建 blob；**blob 传 scope 直接报错**（钉死单周期是存在性推论）。v0.3.1 唯一入口收口继承。
- `update_indicator(inst_id, ...)`：params 变=重声明配方；display_name/auto_label 机制沿用（label(params) 归实例层动态名片）。
- `delete_indicator(inst_id)`：登记处+各 tf 物化一次删净。
- 生命周期：换标的场景不存在 ⇒ **无实例归档**；recipe 跟 K 线重算；轮询新增 bar 时 blob 尾部自然缺根（无害）。
- `scope=board` 语义保留（=定义挂 board、各 tf 含未来新槽自动物化），但这次是模型背书而非户口分裂。

## 4. R4 画板状态机与现场

- board 两状态：**初始（未锁定，仅 AI 可建）** / **已锁定（source_lock 就位，不可变）**。
- 用户侧无空板：所有"新建画板"入口=进新现场搜索流（建板即锁）。
- "删光最后一个板自动补空板"旧规则 → **删光落引导页**（大搜索框+"从雷达添加"）。
- board.name 默认=identity 显示名（symbol display），天然重名治理；board 管理（检索/删除/缩略）由雷达吸收，残余需求留 P2 尾。
- 同标多景合法（技术面板/归因板各自独立），雷达行徽标 ●② 呈现。
- 并发：人/AI 改视图不做锁，last-write-wins + 日志提示（现状机制继承）。

## 5. R5 前端交互（雷达 ↔ 现场）

### 5.1 标的身份定理

**标的 = (源, 裸符号) 二元组**。不存在也不引入"统一标的"命名空间；同物跨源对照=多板/雷达多行。规范化写法只存在于 `list_symbols` 返回的 display 字段（显示层）。

### 5.2 搜索与索引

- 数据源实现 `list_symbols(query)`（CAPS.symbols）→ 标的进**全局索引**；首用全量拉+本地缓存+TTL 日级+手动刷新按钮；**搜索永不穿透打交易所**。
- UI：**标的优先、源在行内**——搜 "BTC" 出 `BTC/USDT | Binance现货 | 价 | ●徽标` 行列表；点行=选完整二元组，一步建板即锁（原"三步流"的选源步已塌缩）。
- 高级输入模式：`@源名 裸符号`（无徽章源）。
- 现场徽标 ●/●②=查"board.source_lock == 该二元组"，搜索结果行同步携带（防重复建板）。

### 5.3 自选栏（雷达，v0.4.1）

- 全局面板（不绑 board），主区三列：左划线工具｜图表｜右自选栏（~240px 可折叠）。
- 行=商品/最新价/涨跌/涨跌%（红绿）；quotes 引擎：3~5s 按源分组批量调 ticker，无 ticker 徽章回退末根 K 线 close；面板折叠暂停轮询（0.4.2 组折叠同规则）。
- 点行三态分发：无板→建板即锁进新现场；单板→直跳；多板→弹现场列表挑选。（§0 旧决议"单击换当前板标的/hover ↗"作废。）

### 5.4 铭牌与摩擦面（四帖全案）

- **A**：Symbol Corner 只读铭牌 `BTC/USDT · ccxt_binance · 🔒`；点击弹**板身份证卡**（source_lock 全展示+周期槽列表+"进入新现场"搜索入口+"在雷达中定位"）——TV 换标肌肉记忆重定向到建板。
- **B**：撞锁（任何路径）→ toast 非红叉，给"用此配置新建画板"一键改道。
- **C**：右键菜单"新建画板"→"进入新现场"。
- **D**：全白户一次性引导浮层（搜索→建现场→AI 分析，三句话）。
- 周期行语义挑明：在线板"+"加周期自动配源（web 发起权）；离线板槽位=自由命名面板。

## 7. R7 WS 协议

### 7.1 标准信封（全量切换，硬切）

```json
{"v": 1, "type": "...", "seq": 42, "ts": 1758219000123, "payload": {...}}
```

- `v`=协议版本；`seq`=每连接自增（排障用，**无 ACK**，恢复=重连重拉 init）；`ts`=服务端毫秒；业务字段全进 `payload`；`init`/`pong` 同款式；前端 switch-by-type 保留、读字段 `msg.payload.x`。

### 7.2 事件表

- 沿用（payload 化）：`ohlcv_update`（**内容差量化，见 §8**）、marker/drawing/subplot/board/timeframe 系列、`view_set`、take_screenshot 触发。
- payload 变更：`indicator_add/update/remove` → inst_id+recipe 摘要。
- 新增 v0.4.0：`kline_source_set`（配置变更，web/agent 发起均广播）、`board_locked`（建板即锁/首配锁）、`scripts_changed`（save_script 后刷菜单）。
- 新增 v0.4.1：`watchlist_changed`、`quotes_update`（分组节流）。
- 时序铁律：**先写状态后广播**（继承 v0.3.1 set_view_range 经验，杜绝读后写竞态）。

## 8. R8 性能三件套

1. **传输增量化**：`ohlcv_update` 只推差量 bars（新增/被改尾部 1~2 根）；前端 `applyDataUpdate`/timeIndex 底子现成；全量仅 init/切换（切换消息携带**窗口**=最近 N 根，非全树）。根治"每拍×全表×被丢弃"。
2. **计算尾窗**：指标重算喂 `max_window`（默认 **5000**）截尾+warmup 给脚本；backfill 左滚同理。脚本指南注明"长记忆参数勿超窗"。
3. **上限护栏**：`max_bars_per_slot`（config，默认 **50000**）——once 脚本/backfill 越界→截最旧+**dropped 回报**（markers 越界同款姿态）；save_script 文件大小告警。专防 AI 手滑大内嵌数据。
- 维持不变：后端全板全周期驻留、**切走不停更**（现场模型命根）。
- 否决勿复活：客户端 LRU 窗口重拉、numpy/parquet 列式（护栏内 LWC+dict 够用）。
